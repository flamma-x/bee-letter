# A small letter about bumblebees

An interactive letter. Static site, no build step.

- `index.html`, `styles.css`, `app.js`, `audio.js`: the whole app.
- `assets/`: media built by `.github/workflows/assets.yml` from `scripts/fetch-assets.sh` (sources generated on Higgsfield).
- Deploy on Vercel as a static project, root directory `/`, no framework.
